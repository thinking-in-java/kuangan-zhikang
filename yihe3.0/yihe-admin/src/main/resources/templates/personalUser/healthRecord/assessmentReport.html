如何改善目前状况降低风险

※目前状况：血压偏高 努力目标：降低血压至120/80mmHg以下

您的血压已高于《中国高血压防治指南》所建议的正常血压范围(＜120/80mmHg)。 您的血压越高，患心血管疾病的危险性就越大。大多数自我感觉健康的人并没意识到他们患有高血压，所以高血压被称为隐形杀手。您应该努力通过改善膳食、运动习惯达到理想血压。 血压超过140/90mmHg或有高血压症状者请向医生咨询有关控制措施。

有助于您降低血压的方法：

（1）超重和肥胖、饮酒过量、膳食高盐是导致高血压的主要危险因素，请注意避免这些因素。

（2）保持积极、乐观、平和的心态，学会正确处理工作生活中的压力。

※目前状况：腰围过大 努力目标：降低腰围

您的腰围已超过正常范围85cm。目前公认腰围是衡量脂肪在腹部蓄积（向心性肥胖）程度最简单实用的指标，脂肪在体内的分布，尤其是腹部脂肪堆积的程度，与糖尿病等肥胖相关性疾病有更强的关联。

对于体重指数不太高者，腹部脂肪增加被认为是独立的危险性预测因素。

有助于您降低腰围的方法：

（1）控制饮食总热量，多选择能量密度较低的食物，如蔬菜、水果、豆制品、杂粮等。

（2）改变生活习惯：吃完饭后不要立即坐下或趴睡，最好能保持站立的姿势，可以选择散步或做家务。

（3）走姿和坐姿要正确；走路时要抬头挺胸、摆动手臂；坐下时脊背打直，不要弯腰或挺腹，如此腰部才不易松垮。

（4）在全身运动的基础上，加强腰部锻炼：30分钟以上的全身运动有助于减少脂肪，从而减小腰围，而腰部运动如呼拉圈、仰卧起坐等，可增加腹部肌肉的弹性，改善体态。

※目前状况：存在高脂饮食 努力目标：控制高脂肪食物的摄入量

你目前的饮食结构为高脂肪型饮食。高脂肪型饮食是指在每天的饮食中，摄入的脂肪所提供的能量超过全天总热量的30%；饮食当中脂肪摄入过多，特别是动物性脂肪的过多摄入，可能会使体内胆固醇增加，继而导致雄性激素生成过多，雄性激素水平的增高是诱发前列腺癌的危险因素之一，因此在日常膳食当中应控制高脂肪食物的摄入量。高脂肪的食物包括肉类（尤其肥肉）、油炸食品及奶油蛋糕（多数市售奶油蛋糕）、动物油脂、植物油等。

有助于您控制高脂肪食物的摄入量的方法：

（1）少吃或不吃高脂肪的食物：如肉类（尤其肥肉）、油炸食品及奶油蛋糕（多数市售奶油蛋糕）、动物油脂、植物油等。

（2）适量增加低脂肪的食物：所有的蔬菜和水果、大多数的鱼类（三文鱼、鳗鱼等脂

（3）减少烹调用油，在烹调时多采用煮、蒸、凉拌等烹调方法。

危险因素控制目标及改善途径

※目前状况：血压偏高 努力目标：降低血压至120/80mmHg以下

您的血压为118/89mmHg，已高于《中国高血压防治指南》所建议的正常血压范围(＜120/80mmHg)。 您的血压越高，患心血管疾病的危险性就越大。大多数自我感觉健康的人并没意识到他们患有高血压，所以高血压被称为隐形杀手。您应该努力通过改善膳食、运动习惯达到理想血压。 血压超过140/90mmHg或有高血压症状者请向医生咨询有关控制措施。

有助于您降低血压的方法

（1）超重和肥胖、饮酒过量、膳食高盐是导致高血压的主要危险因素，请注意避免这些因素。

（2）保持积极、乐观、平和的心态，学会正确处理工作生活中的压力。

※目前状况：腰围过大 努力目标：＜85cm

您的腰围为89cm，已超过正常范围（< 85cm）。 目前公认腰围是衡量脂肪在腹部蓄积（向心性肥胖）程度最简单实用的指标，脂肪在体内的分布，尤其是腹部脂肪堆积的程度，与糖尿病等肥胖相关性疾病有更强的关联。 对于体重指数不太高者，腹部脂肪增加被认为是独立的危险性预测因素。

有助于您降低腰围的方法：

（1）控制饮食总热量，多选择能量密度较低的食物，如蔬菜、水果、豆制品、杂粮等。

（2）改变生活习惯：吃完饭后不要立即坐下或趴睡，最好能保持站立的姿势，可以选择散步或做家务。

（3）走姿和坐姿要正确；走路时要抬头挺胸、摆动手臂；坐下时脊背打直，不要弯腰或挺腹，如此腰部才不易松垮。

（4）在全身运动的基础上，加强腰部锻炼：30分钟以上的全身运动有助于减少脂肪，从而减小腰围，而腰部运动如呼拉圈、仰卧起坐等，可增加腹部肌肉的弹性，改善体态。
