小程序消息通知
将以小程序消息，即在个人中心的小信封图表中的“互动”中呈现。 注意：不会有微信提醒，需要用户自行进入小程序的消息通知中查看。

事件类型：站内信
备注：给您发送了一条健康管理服务信息，请及时查阅，祝您健康！
