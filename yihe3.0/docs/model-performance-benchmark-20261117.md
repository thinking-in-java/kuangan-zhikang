## 历史样本一并统计

同配置12并发的此前两次识别耗时为54.531、46.406秒；加上本轮24.203、26.031、29.719秒，共5次平均36.178秒，最短24.203秒，最长54.531秒。
因此当前可表述为：本轮平均约27秒；包含此前慢样本的平均约36秒，尚不能承诺稳定30秒内。

## 计时口径

包含本地PDF文字提取/渲染、所有页面模型请求、页级有限重试及候选JSON组装；不包含浏览器上传耗时、字典预加载、数据库候选入库和医生审核时间。
逐页记录实际HTTP次数、状态码、耗时、输出长度与token统计，不记录密钥或请求原文。所有页面仍按原页码合并。
