# 问卷测评业务闭环

## 运行方式

`/assets/assessment/questionnaires.html` 默认连接业务库。`?mode=demo` 仅保留原竞赛演示；正式入口不会在请求失败时回退为演示数据。六个页面沿用现有布局。

执行 `database/migrations/V036__questionnaire_workflow.sql` 后启动新版。该迁移仅增加配置、处理队列和系统内提醒表，不清空历史表。已在本机业务库及预览库执行。

## 已接通的链路

1. 分类、题目、自编量表存入当前单位、当前数据域的配置表；带版本检查和请求幂等，拒绝覆盖其他人的更新。
2. 内置题目来源、评分及版本受保护。标准量表发布必须完整；自编题目可维护选项、分值、反向计分、启停及分级区间。
3. 新建问卷四步配置保存到后台。初始化提供两份未发布草稿：PHQ-9 + GAD-7 情绪焦虑筛查、煤矿工作适应与支持需求调查。没有虚构任何答卷或参与人数。
4. 发布前明确选择接收职工，后台再次核验单位权限。冻结题目、选项、评分来源及设置，创建本人待办。同一请求重放不重复发放；发布版本不能覆盖，需复制新草稿。
5. 员工通过 H5 本人账号或已有小程序问卷 API 读取本人待办并提交。服务端核验开始/截止时间、必答题和选项归属，拒绝重复提交及客户端伪造分值。
6. PHQ-9、GAD-7 分别计分和解释，不把合计分当作综合临床分数。PHQ-9 第 9 题存在非零响应时独立生成需及时人工评估标记。
7. 心理小谷使用持久化队列、2 个分析线程调用现有独立模型 API。外发仅临时编号、量表代码/分值、完整性及条目信号，无姓名、身份证、手机号、部门或自由文本答案。模型不参与改分。失败状态、人工重试和中断回收均保留。
8. 医生可明确选择审核决定、确认风险等级并写意见；批量操作在单一事务中完成，版本或权限不通过时整批回滚。AI 初筛与医生结论分开记录。
9. 审核后的分量表测量值接入现有心理评估数据表。配置允许且达到关注条件时创建待执行干预记录；可填写完成结果、复测安排。归档保留原始答卷。
10. 系统内自动提醒按配置间隔和最大次数生成，已提交/到期对象不继续提醒。手动提醒同日去重。
11. 员工个人结果按照反馈权限及“审核后开放”规则显示。统计和历史查询由实际发放、提交及审核记录计算，部门统计只基于本单位可见数据；混合量表历史不展示无意义的合并均分。

## 数据来源

内置 `questionnaire-catalog.json`：22 道题，6 个量表条目。

- PHQ-9：9 题；0–27 分；按作者说明区分 0–4、5–9、10–14、15–19、20–27 分。GAD-7：7 题；0–21 分；区间 0–4、5–9、10–14、15–21。中文呈现为参考版本，保留专业核对适用性的说明，不声称新译文经过临床验证。
- 煤矿工作适应与支持需求调查：6 道本项目自编题，仅用于工作支持需求调查，不伪称标准心理量表、不配置臆造临床分级。
- PSS-10、PSQI、SCL-90：来源元数据，题目数 0、停用并标识待授权版本导入。没有复制不明来源的题目或凭空补足截图题量。

主来源：

- 作者 PHQ / GAD 使用说明及许可：https://www.uab.edu/medicine/pcp-sci/images/SCIMS/PHQ-9_Instruction_Manual.pdf
- PHQ 官方入口：https://www.phqscreeners.com
- Pittsburgh PSQI 原版权/译本及七成分计分：https://www.sleep.pitt.edu/psqi
- Carnegie Mellon PSS 使用条件（明确没有诊断切分值）：https://www.cmu.edu/dietrich/psychology/stress-immunity-disease-lab/scales/

## 仍待接入，不能当作已完成

- 匿名调查尚未建立独立的匿名授权和个人干预模型，因此当前正式发布只支持实名本人授权，界面禁用匿名选项。
- 短信、邮件、微信模板主动推送需要实际供应商配置；当前生成的是系统内待办/提醒，不宣称已送达手机。H5 已接通，小程序端可复用现有个人会话及问卷接口，未在真实微信客户端验证。
- 问卷答题分钟数配置目前仅作为安排信息，未建立服务器端答题计时会话；开始和截止时间由服务器强制检查。
- PSQI、PSS-10、SCL-90 等完整授权中文题目及专用评分包待提供。不得将 PSQI 的 19 个题简单相加，也不得为 PSS 任意制定标准风险阈值。
- 部门级 AI 结论及汇总医生签署尚未建立独立流程，页面明确指向个体答卷，不显示伪造摘要。
- 干预记录提供负责人、执行完成与复测安排留痕；外部心理师预约或消息通知未接通。
