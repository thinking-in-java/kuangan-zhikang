# 题库与量表补充包（2026-11-27）

## 内容和来源

- 原有 22 题、6 个量表条目不删除。追加 2,239 道题和 18 个量表/自编调查条目，合计 2,261 题、24 个条目。
- 新增 2,160 道原创服务需求调查题，覆盖 18 类、180 个具体主题，每个主题有行为、理解、把握、指导经历、可用条件、障碍、咨询渠道、支持满意度、帮助需求、服务形式、联系意愿、建议 12 个维度。不是从网上抓取的 2,160 道已验证试题；不宣称独立心理测量效度。应按目的选题，不应一次发放整个题库。
- 参考中国疾控中心职业健康素养 60 条、2024 年健康素养和 NIOSH 职工福祉领域框架后原创编写，不复制 NIOSH 单项受限题目。原创题中1,620题采用本项目管理评分，540题仅收集偏好、联系意愿和文字建议；允许不适用、不愿回答，默认非必答。
- 6 个新增开放标准版本：PHQ-2、GAD-2、PHQ-8、PHQ-4、DASS-21、DASS-42，共79题。PHQ/GAD短版使用现有中文版同源条目。短版与长版存在同源重叠，新增题数是题库版本条目数，不是79个互不重叠构念。
- 12 份自编、18 题支持需求调查：粉尘、噪声、高温、肌骨、化学因素、体检、轮班睡眠、压力、情绪支持、班组支持、工作适应、疲劳与安全。清楚标注自编、非诊断、未经信效度验证，不称为标准心理量表。
- PSS-10、PSQI、SCL-90 仍保持原有待授权状态，不用未知来源题目冒充正式版本。

准确来源、许可与条目数见 `questionnaire-supplement-manifest.json`。DASS-42 为官方站点公开的 Zuo/Chang 简体译本；21题中文参考呈现按英文21题与42题对应条目抽取，不声称该呈现经过新的中国煤矿人群验证。正式使用前由本单位专业人员核对。

## 计分

### 自编管理评分 management-v1-20261127

这些分值和分档由本项目定义，用于安排健康教育和支持服务；未经信效度验证，不代表疾病或职业健康医学风险。

| 题型/维度 | 选项分值 | 含义 |
| --- | --- | --- |
| 行为落实、信息理解、行动把握 | 3、2、1、0 | 越高表示落实/理解/把握越充分 |
| 接受指导 | 3、1、0；记不清不计分 | 越高表示指导可及性越充分 |
| 可用资源（多选） | 4项资源各1分，条件不足0分，满分4分 | 越高表示资源越充分 |
| 实际困难（多选） | 5项困难各1分，没有困难0分，满分5分 | 越高表示障碍越多 |
| 咨询可及性 | 3、1、0 | 越高表示咨询渠道越方便 |
| 支持满意度 | 3、2、1、0；尚未获得服务不计分 | 越高表示对已获得支持越满意 |
| 帮助需求 | 3、1、0；不确定不计分 | 越高表示希望获得帮助越迫切 |
| 支持形式、联系意愿、文字建议 | 不计分 | 不根据偏好或拒绝联系评价个人 |

- “不适用／不愿回答／无法判断”保留原始答案，分数为null，排除评分分母，不当成0分。多选中的“没有困难／条件不足／不需要额外支持／不适用／不愿回答”等与其他项互斥，后端同样校验。
- 同一维度指数 = 有效题得分合计 ÷ 有效题满分合计 × 100，保留1位小数。正向维度与困难/需求维度各自汇总，不输出混合总分。
- 无有效答案返回“未计分”，不当成0分。有效计分题不足该维度50%时只显示分数及覆盖率，不分档。
- 本项目管理分档：0–25、>25–50、>50–75、>75–100。正向维度对应“待重点完善／建议加强／基本具备／较充分”；困难与需求对应“较少／一般／较多／较集中”。这些是自定义服务管理区间，不是经过验证的心理量表或医学阈值。
- 逐题规则和排除标记随发布版本冻结；旧问卷、历史答卷不重新计分。管理指数不写入正式心理量表测量表。

- DASS分别输出抑郁、焦虑、压力三分量表；21题版各分量表乘2，不输出混合诊断总分，无自行设定的临床风险阈值。量表题目不得修改或单独售卖。
- PHQ-4分别呈现两题焦虑、两题抑郁维度。不把两者合计成疾病风险。
- 新增PHQ短版说明分数含义但风险保持未核定；需要专业人员结合实际判断。PHQ-9原有第9题非零的独立人工关注标记保留。
- DASS个人端不展示自动分数解释、不开放自动模型解释；由专业人员解释，发布强制审核后开放，审核后的个人端仅展示医生意见。
- 原始时间窗保存在冻结题目的description中，个人填写界面逐题可见。已发布历史版本不追溯改写。

## 导入与回退

1. `python scripts/build_questionnaire_supplement.py` 可重复生成稳定ID的数据包、标准量表目录和清单。
2. 启动新版本，授权医生登录。题库和量表页的“导入扩展资料”调用 `POST /ehr/api/questionnaire-center/catalog/import-supplement`，沿用CSRF、当前单位、数据域、行版本与请求幂等校验。请求为 `{"version":当前资料库版本,"requestKey":"UUID"}`。
3. 只追加不存在的题目/量表/分类ID。已有ID不覆盖，重复导入新增数量为0。数据库沿用 `a_questionnaire_center_state` 和已有审计/请求回执表，不新建无前缀表。
4. 导入不发布问卷、不生成答卷、不生成职工数据、不通知员工，不修改健康档案或历史发布内容。
5. 导入前应保存当前资料库快照。实际导入仅针对当前授权单位和数据域，其他单位可自行从页面导入，避免全库广播式填充。
6. 普通编辑仍检查行版本并限制每类5000条；配置体积上限提升至800万字符，容纳真实千题题库。不得绕开版本检查覆盖同事修改。
7. 已导入旧版零分题库时，“配置管理评分”调用 `POST /ehr/api/questionnaire-center/catalog/configure-management-scoring`，请求同样包含当前version和requestKey。逐项对照旧版完整数据，只更新未被手动编辑过的2,160道原创题和12份调查，跳过修改项并返回ID；重复配置零更新。不修改标准量表、问卷草稿、发布版本、答卷和审核记录。

## 验证

`QuestionnaireSupplementChecks` 和 `QuestionnaireManagementChecks` 不连接数据库，检查数量、唯一ID、原创题干去重、来源、题数一致、DASS题号分组、21题乘2、原始PHQ及受限量表保留，以及管理评分正反方向、互斥多选、不适用排除、有效分母、低覆盖不分档、全排除不产生0分和实际发布冻结路径。上线后检查追加数量、再次配置零更新、历史内容不变、题库预览与实际规则一致。
