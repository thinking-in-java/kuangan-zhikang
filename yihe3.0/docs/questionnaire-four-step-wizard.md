# 心理问卷四步演示向导

在现有 questionnaire-center.js 中扩展，保留 mode=real 原正式业务入口。

1. 基本信息：名称、类型、多选量表、对象、起止时间、答题渠道、匿名/AI、预警、题目来源及数量。创建并下一步保存草稿并进入步骤2。
2. 题目配置：量表检索多选、题库选择、自定义题目、整组与单题排序/删除，保存来源和量表版本。尚无原文的量表条目明确标待导入，不伪造标准题目。
3. 评估设置：评分方式、各量表四级区间、AI/预警/干预开关及反馈对象。区间校验从0开始、连续无重叠。默认区间仅为参考图演示配置，未核定为正式标准计分包。
4. 发布确认：对象/单位/工号范围、排除人员、渠道、起止时间、答题时限、提醒间隔上限、查看权限、报告开放时机。需核对确认后模拟发布。

配置及演示发布记录存浏览器 localStorage；不会发送真实消息、短信、邮件或小程序通知，不调用心理API，不生成真实职工任务/作答。正式后台调度、授权量表计分、隐私权限执行、实际发送及参与状态追踪仍待对接。

验证：Playwright覆盖16题汇总、自定义题、组删除、分数区间错误、上下步保留、模拟发布记录和刷新保留；构建另见 runtime 日志。
