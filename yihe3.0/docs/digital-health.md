# 数字健康师：页面与悬浮医生

本阶段只实现页面、医生形象和交互预览，不接大模型、业务统计或自动任务。

## 开源组件与参考

- [Deep Chat](https://github.com/OvidijusParsiunas/deep-chat)：使用本地 `deep-chat@2.5.1` Web Component，MIT 许可证保存在 `static/assets/vendor/deep-chat/LICENSE`。
- [Live2D Widget](https://github.com/stevenjoezhang/live2d-widget)：调研了网页悬浮角色的交互形式，本次未引入其代码或模型。
- [Three.js](https://github.com/mrdoob/three.js)：本地 `three@0.187.0`，MIT 许可证保存在 `static/assets/vendor/three/LICENSE`。用于原画驱动的分区网格骨骼变形。

## 入口

登录后台的全局右下角显示医生入口。点击打开悬浮对话面板，可收起、使用快捷按钮或进入工作台。

支持鼠标或触摸拖拽位置，限制在可视窗口内，拖动结束不会误触打开对话。打开的面板与提示气泡按娃娃位置计算并避免越出窗口。缩放窗口时会重新限制位置。位置仅在本次页面中保留。

娃娃具有呼吸浮动、悬停/拖拽后的轻微摆动、进入页面后的问候和约 55 秒一次的空闲陪伴提示。提示均为界面操作引导，不伪装成真实告警或任务结果；可关闭气泡或点击进入对话。后台标签页、完整工作台或已展开对话时不主动弹出新气泡。

已有“健康评估”菜单权限的账号，会在该组下看到“数字健康师”。该入口加载 `/assets/digital-health/index.html`；只增加页面预览，不扩大服务端业务权限，不修改权限数据库。工作台打开时隐藏全局悬浮角色，避免重复。

## 账号形象

主模板从当前 Shiro 登录用户传入账号编码、登录名称和 `gender`：1 显示男医生，2 显示女医生，其他值显示中性平台标识。完整工作台从同源父页面读取这三个基本字段。单独打开静态预览页时使用中性形象。

- `static/assets/images/digital-doctor-male.png`
- `static/assets/images/digital-doctor-female.png`

两张原始资源均为 RGBA 透明图片，已保存在项目内。脸型、发型、身体和持平板的手继续使用原画，主体为 14,065 顶点的 SkinnedMesh。自由手臂改成独立的 2,425 顶点校正网格，使用自然垂手、中间姿势、原始招呼姿势三个正确手型进行连续形变。以画面左右标记：自由手臂在画面左侧，是人物自身的右臂；画面右侧持平板的是人物自身的左臂。禁止镜像互换两只手，也不再将掌心朝上的原画旋转 180 度作为垂手姿势。

待机时手自然放下；招呼持续约 5 秒，经历抬起、轻微手腕挥动、放回。重复悬停不会不断重启动作、让手一直抬着。新增微笑入口，保留点头、歪头聆听、自动眨眼和轻微呼吸。闭眼和嘴角变化通过脸部局部着色实现，持板手臂仅有很小的待机幅度。动作资源与内置图像工具的生成提示词见 [digital-doctor-animation-assets.md](digital-doctor-animation-assets.md)。

这是 2.5D 原画网格动画，不是可以绕到背面查看的完整高精 3D 人物模型。减少动态效果偏好会降低自动动作；WebGL 不可用、素材加载失败或首次着色器编译失败时保留原始静态形象并标注“静态备用”，避免隐藏原画后只剩手臂。

本次验证包括男女两种形象各 51 个抬手位置的手部三角形朝向（不得反转）、抬手后回到垂手、重复触发、持板手隔离、微笑/头部/眨眼、真实 Deep Chat 与拖动回归。另用 NVIDIA OpenGL 离线编译实际自定义片元代码、导出生产网格并渲染多帧，人工核对掌心、拇指、袖口和身体完整性。桌面预览工具因为不能确认浏览器 URL 而中断，因此这不等于实页浏览器验收；需刷新实页查看最终呈现。

## 交互范围

悬浮面板提供今日日报、立即扫描、紧急事项、数据概览、自主规划、今日日程六个预览入口。完整页面提供对话、新建会话、会话搜索、演示职工上下文与服务概览布局。

所有回复均为明确标注的预设示例，不调用远程模型，不扫描职工数据，不创建随访或干预任务。统计卡片显示 `—`。材料选择只展示文件名，不读取内容、不上传、不识别；语音按钮只提示入口预留，不申请麦克风权限。会话仅存在当前文档内存，不启用浏览器持久化，不写数据库。

## 后续接入

可将 `digital-health.js` 中 Deep Chat 的 `connect.handler` 替换为同源 Java 接口调用。模型密钥应保留在服务端。真实数据需要按登录用户权限查询，业务执行需在清晰展示对象与内容后再增加审核流程；当前页面未实现这些能力。
