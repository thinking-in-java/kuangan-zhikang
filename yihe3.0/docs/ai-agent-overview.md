# AI 数字员工中心 · AI 智能体总览

入口：现有后台侧边栏「AI 数字员工中心 → AI 智能体总览」。页面地址 `/assets/agents/overview.html`。保留既有数字员工协作中心及所有业务页面。

## 页面及交互

按用户参考图实现矿井横幅、六个今日统计项、五位机器人卡片、近7天趋势、今日职责分布、实时任务动态及协同业务流程。机器人形象以用户原图作为CSS局部图像显示，没有重画角色；主背景与横幅复用系统素材。

- 今日统计、员工任务数、分布图及图例可打开任务列表。列表支持员工、状态、创建时间范围、姓名/工号/标题筛选及分页跳转。
- 查看任务后可返回原筛选与页码。列表条件保存到页面URL，刷新继续显示。任务详情链接指向已有业务模块，权限及办理流程由原模块控制。
- 五个员工姓名及「进入工作台」连接已有工作台并指定员工；侧边栏也提供五个工作台、任务调度中心及AI执行记录入口。
- 实时动态可查看关联任务；协同流程是业务导航，不会一键自动修改档案、发送通知或发布建议。
- 每15秒刷新，页面隐藏或任务弹窗打开时暂停轮询，手动刷新保留当前业务数据，错误时有重试入口。
- 支持1920、1366及390宽度。大屏横排五卡，窄屏重排，流程/任务表在自身容器内滚动。保留现有平台侧边栏与顶部工具栏。

## 数据口径

新API是只读视图，汇总八类已有记录：派活任务、OCR、当前医生授权的指标预警、AI体检评估、综合健康分析、慢病风险分析、职业健康风险分析及心理评估。后五类分别归属评估小谷或心理小谷。不同业务步骤按独立任务计数，不伪装成同一端到端任务。

今日按北京时间当日创建的任务队列统计。7天趋势按创建日分组，已完成线表示这些创建队列的当前完成情况。员工「今日完成率」为今日创建任务中已完成任务占比，无任务时为「—」。卡片状态按全部时间的正在执行任务及接单配置展示；「执行中」不表示已检测到进程心跳。空闲、暂停接单按实际数据区分。

AI任务生成结果后若尚待专业审核，计入「等待人工审核」，不计入「已完成」。综合健康分析只有已有审核记录才作为完成。失败、重试等待及取消状态分别映射为失败、排队和取消，保留来源原状态。最新动态按实际更新时间取前5条，可以来自之前创建的任务。

现有表没有保存全部模型调用的完整Token用量，因此该项返回null，显示「— / 待接入完整计量」。没有伪造截图任务数、完成率、Token、进程状态或新评估结果。

API要求当前单位授权后台医生，阻止移动端及非医生读取；按单位与真实/测试数据模式隔离。记录已删除时不展示该职工身份，关联评估不提供原资料链接。接口使用 `private, no-store`，没有新增写接口、数据库表或模型调用。

## 文件与API

- `yihe-admin/src/main/resources/static/assets/agents/overview.html`、`overview.css`、`overview.js`：页面、样式、图表与交互。
- 同目录 `overview-reference.png`：用户提供的原图，用作机器人形象的局部背景图像。
- `yihe-admin/src/main/resources/templates/index.html`：独立菜单与平台浮动助手显示范围。
- `yihe-framework/src/main/java/com/yihe/framework/ehr/AgentOverviewService.java`、`AgentOverviewController.java`：只读汇总与任务查询。
- `DigitalWorkerTaskHub.java`：将已有查询构造方法开放为包内复用，原查询行为不变。
- `tests/ehr/java/AgentOverviewChecks.java`：40项预览库事务回滚测试。

API：GET `/ehr/api/agents/overview` 返回今日汇总、员工分布、全部时间活跃状态、7天创建队列趋势、最新动态及计量可用性；GET `/ehr/api/agents/tasks` 支持 `worker/source/status/period(today|all)/search/page/limit`。
