## 真实数据和交互

- 复用八类已有任务来源，不生成截图中的固定任务数、风险结果、完成率或假进度。
- 工作台支持任务类型、状态、时间范围、姓名/工号/任务内容筛选，状态标签、分页、每页条数与页码跳转，选择/全选、CSV导出及JSON详情导出。URL保存筛选及页码，刷新恢复。
- 左侧选择任务，右侧读取其真实元信息、已保存的输出与操作事件。Markdown标题和重点内容经过转义后排版，任务输出不能注入HTML脚本。
- 可查看完整结果、复制、查看全部日志、跳转原业务模块；派活和处理/审核使用已有 `DigitalWorkerDispatch`，沿用原有授权、版本校验、CSRF与审核状态机。新接口不提供写入、发送或自动临床处置能力。
- 五个员工任务已按现有角色范围查询。工作台状态按实际执行任务及现有接单配置显示；没有进程心跳时不宣称后台进程在线。
- 调度流程是明确标注的导航示例，不将不同职工、不同任务的状态拼成一个已运行的自动流程。岗位策略配置跳到原岗位配置页面，已有策略真实保存。
- 今日统计采用北京时间当日创建队列；昨日及7/30/90天趋势采用同一时区。AI完成分析而未专业审核的记录仍计待人工确认。今日列表/筛选与全部时间队列分开，当前执行面板可显示跨日活跃任务。
- Token用量、端到端自动化率、完整逐次工具/接口调用链、通知发送回执和方案模板库未具备完整接入条件时，明确显示“— / 未记录 / 待接入”。不会把缺失计量当作0，也不会生成截图中的工具调用、诊断、风险级别或通知成功记录。
- 方案及关怀建议仍为待专业核对的输出；未核定的风险显示未核定，不推算缺失的分项风险或时间进度。

每15秒自动刷新，输入、页面隐藏或对话框打开时暂停轮询。错误显示重试，任务已删除或跨单位无权限时不展示原资料输出。

## 接口与权限

GET `/ehr/api/agent-workspaces`：支持 `worker/type/status/period(today|all)/search/page/limit/days(7|30|90)`，返回今日/昨日/全部汇总、趋势、类型分布、当前/已完成/待审/失败任务面板与分页列表。风险仅在专业确认时作为已核定结果展示。

GET `/ehr/api/agent-workspaces/task?source=...&id=...`：在统一视图中验证单位、数据模式和来源归属后读取该任务的已有结果与事件。所有读取仅允许授权后台医生，拒绝移动端及非医生。绑定源档案已删除时保留任务元信息，不返回旧输出；所有响应设置 `Cache-Control: private, no-store`。URL参数显式命名，已通过实际HTTP绑定检查。

写入全部复用已有 `/ehr/api/digital-worker-tasks` 与原业务模块接口，不新增数据库直写通道。
