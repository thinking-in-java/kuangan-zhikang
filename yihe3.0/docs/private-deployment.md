# 数据库部署与私有配置

主库配置从环境变量读取：

| 变量 | 用途 |
| --- | --- |
| `EHR_DB_URL` | JDBC 地址，默认 `192.168.1.109:3306/shayu_3.0`（保留配置中的连接参数） |
| `EHR_DB_USER` | 数据库账号，必须配置 |
| `EHR_DB_PASSWORD` | 数据库密码，必须配置 |

也可使用仓库外的 `application-druid.yml`，通过 Spring 的 `spring.config.additional-location` 加载。密码变更后更新部署环境变量或私有配置，重启应用；GitHub 代码中的变量名无需更改。

`kuangan_dev_122` 是仅允许 `192.168.1.122` 登录的独立开发账号，不是 root 密码变更。其他电脑或服务器需要各自授权账号，不能直接复用该账号。

`database/reference/shayu_3.0-schema-only.sql` 是 2026-11-23 的表结构快照，无数据行、账号授权、视图、存储过程或触发器。仅用于空库建表参考；已有库使用 `database/migrations` 下的版本迁移，不要直接覆盖。业务表之外的应用基础数据需由管理员通过私有途径提供。

职工姓名、身份证件、联系方式、体检结果、报告原件、数据库全量备份和 API 密钥保留在私有存储，不进入代码仓库。全量数据迁移使用单独的加密备份和受控传输。
