# 评估小谷：慢性病自动初筛

保留 `/assets/assessment/chronic-risk.html` 页面。职业健康与慢病分别使用任务队列、来源快照、结果表和医生审核记录，不共用风险等级。

## 触发与输入

报告完成 OCR、身份关联和质量校验，行政入档后，`ChronicAutomationService` 每 30 秒扫描有可信检查数据的职工，每轮最多新增两个慢病任务；`ChronicRiskWorker` 两份并发调用独立数字员工模型配置。此流程不要求先完成所有医疗审核，但未审核资料始终带状态标记。身份尚未确认或没有可信项目的上传不会伪装为已评估。

新报告、报告版本、个人基础资料、既有体检评估及其审核状态、健康补充资料或规则发生变化时生成新版本；相同来源不重复调用，失败不无限自动重试。手动批量评估仍可使用。旧结果保留，来源变化或医生退回的结果不计入当前等级。

输入包括当前可信体检报告、可用历史、原值、单位、参考范围、原件页码、年龄性别和既有体检评估。补充资料通过单位范围内的 `/ehr/api/assessment/chronic/profiles/{record}` GET/POST 管理：既往诊断与病史、用药、家族史、吸烟、饮酒、饮食运动、睡眠。写入需要医生权限、CSRF 与乐观版本，变更留存 before/after 审计；未询问保留空白，不自动填写为“无”。原报告中的相关病史同样保留原件证据。

出站使用临时 `SUB-…` 和证据编号，移除姓名、工号、身份证、电话、生日、单位和日历日期；原身份、日期与报告版本保留本地。模型只分析给定报告截面和可比较的历史顺序，不虚构年份或时间间隔。

## 五类独立结果

- 高血压：血压、收缩压、舒张压及有来源的相关病史。
- 糖尿病：血糖、葡萄糖、糖化血红蛋白与相关病史。
- 血脂异常：总胆固醇、甘油三酯、LDL、HDL 等。
- 肥胖：身高、体重、BMI、腰围等。
- 心脑血管：结合可用年龄、性别、血压血脂血糖及病史、生活方式和家族史。

每类保存建议等级、数据状态、依据编号、分析、历史分析、建议及待补项。缺少该类依据必须 `insufficient / unknown`，不能默认低风险；有足够依据的分项可正常分析。总体建议不能低于最高已评分项；全部分项都缺资料时不能强行生成低风险。未采用经过验证的评分模型，因此医学分数与患病概率不编造，`riskScore` 保持 null。

模型返回必须满足 JSON schema、临时编号一致、五类完整、依据确实存在及类别相关性要求；数值与页码由本地证据解析。原报告未写建议不阻塞初筛，AI建议与原医嘱区分。结果保存模型、用量、耗时、来源和版本，失败或被取消的晚到结果不会标为成功。

## 审核及展示

当前看板按有效 AI 初筛建议展示，医生已确认的等级优先；五类分别统计，缺资料的类别不纳入低风险。历史趋势继续明确标为当时的医生确认快照，不把 AI 草稿追认为过去的医疗结论。

医生审核表预填 AI 建议，可修改后明确确认，并沿用原件、身份与既有权限核验；也可退回补充。自动过程不写入已确认医疗风险台账，不诊断、开药、调药、发送通知或执行干预。既有“方案小谷准备任务”入口保留其原审核机制。

数据库变更：`database/migrations/V035__chronic_dynamic_screening.sql`，含新结果字段、健康补充资料及审计表、拒审状态和任务领取协议保护。相同数据库上的旧服务不能误领新协议任务。

## 医学边界与验证

单次异常是复核线索，不是新的确诊。参考[国家卫生健康委高血压日宣传资料](https://www.nhc.gov.cn/ylyjs/gzdt/202409/bfc23c5086044eb0b4879e58e4df69e1.shtml)中规范重复测量的原则。疾病诊断、适用标准和必要检查由医生判断。

新增纯规则与预览库事务回滚测试覆盖独立分类、缺项不默认低风险、无关证据拒收、英文医院字段别名、去标识化、来源改变、队列去重、补充资料权限/版本、医生退回及两个任务表的隔离。局域网 HTTP 的请求编号使用 `getRandomValues` 回退，避免重复出现 `randomUUID is not a function`。
