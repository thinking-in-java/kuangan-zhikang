# 题库管理演示模块

现有问卷中心的 section=2 使用分类、列表、详情三栏布局。新建分类保存上级、名称、描述、图标、顺序、启用状态。题目保存关联分类和量表、题型、唯一编号、内容说明、选项原始与有效分值、反向计分、随机选项、启用/必答/常用及顺序。

支持题库过滤、分类搜索、预览、复制、批量启停、JSON导入导出与编辑回显。单选、多选、李克特、文本题型均可配置；文本题不强制选项。反向计分保存有效值（最高原始分+最低原始分-当前原始分）。配置保存在本浏览器演示数据中，不接收真实职工作答或执行临床评分。

已验证新增分类、题目五选项、多选反向计分、必答、编辑回显、批量停用、刷新保留、4种宽度和无JS异常。
## 题目预览与编辑弹窗（2026-11-27）

- 预览：电脑端/移动端切换，单选、多选、文本题展示，上下题浏览，临时答案保留，显示常规/反向预览得分和题目信息。
- 编辑：沿用新增题目表单，回显内容、选项原始分值、计分方向、状态、必答、常用及排序；修改保存至浏览器演示题库。
- 预览不会提交职工答卷，也不会根据单题分数生成健康诊断。
- 自动验证：`tests/ehr/verify-question-preview.cjs`。默认覆盖本地源码；`DEPLOYED=1` 时验证运行服务。测试使用独立浏览器上下文并清除测试演示数据。
- 本次只完善现有演示模块，不变更 `?mode=real` 原有业务接口。
